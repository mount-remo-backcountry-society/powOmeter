POW-O-METER: station data

Snow station of the Mount Remo Backcountry Society, Shames Mountain, BC. This page lists the data files; a proper station page will follow.

Checking how recent the data are…

latest.jsonMost recent value of each variable
best.csvBest available readings (large)
best_hourly.csvInterpolated to whole hours (not hourly means)
observations.csvEvery reading, all statistics, with quality labels (large)
status.jsonStation health and alarms
sites.jsonStation sites, coordinates, licences
SCHEMA.mdWhat every column means. Times are UTC
CHANGELOG.mdChanges to the file format

Values are provisional unless labelled approved. Station data are not a forecast: check the avalanche forecast at avalanche.ca. Data: CC BY 4.0, credit "Mount Remo Backcountry Society".
